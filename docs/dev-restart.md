# Перезапуск локальной разработки

## Когда перезапускать

- После изменения `.env`, `AGENT_BRIDGE_SECRET`, `AGENT_URL`, `API_URL`, `APP_URL` или чего-либо из `passThroughEnv`.
- После миграций базы данных.
- Когда приложение, API или агент не отвечают.

## Полный перезапуск

Все команды Turborepo выполняются **из корня репозитория**, а не из `apps/app` или другого пакета.

```sh
cd /Users/antony/Documents/dev/trycompai-crm
bun run dev
```

Если нужно вызвать turbo явно:

```sh
bun run turbo run dev
```

Это запускает все пакеты: Next.js-приложение на `http://localhost:3100`, Nest API на `http://localhost:3101` и Eve-агента на `http://127.0.0.1:2000`.

## Только агент без TUI

Если терминал не может отобразить Eve TUI, используй из корня репозитория:

```sh
turbo run dev:headless --filter=agent
```

## После редактирования `.env`

1. Останови запущенный Turbo.
2. Запусти его заново командой выше.

Turbo читает переменные окружения из рабочей директории при старте. Уже запущенный процесс держит старые значения до перезапуска.

## Частые порты

| Сервис | URL |
| --- | --- |
| Приложение | `http://localhost:3100` |
| API | `http://localhost:3101` |
| Агент | `http://127.0.0.1:2000` |

## Занятые порты

Если порт уже используется:

```sh
lsof -nP -iTCP:2000 -sTCP:LISTEN
```

Найди PID и останови процесс перед перезапуском.
